# 📌 MEAN Stack Basic Item Viewer

A simple full-stack web application built using the **MEAN stack (MongoDB, Express.js, Angular, Node.js)** that displays a list of items stored in a MongoDB database.

---


---

## ⚙️ Backend Setup

### 1. Install dependencies

```bash
cd backend
npm install
```
### 2. Start backend server
```bash
npm start
```

## 🎨 Frontend Setup

### 1. Install dependencies

```bash
cd frontend
npm install
```

### 2. Run Angular app

```bash
ng serve
```
